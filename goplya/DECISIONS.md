# Журнал решений (DECISIONS.md)

## Общие решения

1. **Структура репозитория**: Файлы спецификации и документации перемещены в `docs/` согласно структуре из спецификации. Исходный код в `src/goplya/`.

2. **Кодировка и переносы строк**: UTF-8 везде. Принимаем `\n` и `\r\n`. BOM игнорируется при чтении.

3. **Точка входа CLI**: `гоп = goplya.cli:main` в `pyproject.toml`. Команда `гоп` доступна после установки пакета.

4. **Версия интерпретатора**: 2.2. Файлы с версией выше 2.2 выдают ошибку E012.

5. **Порядок аргументов CLI**: `гоп запусти файл.слыш [--без_пауз] [--сеть]`, `гоп проверь файл.слыш`, `гоп --версия`, `гоп собери файл.слыш`.

## Решения по лексике и парсингу

6. **Идентификаторы**: Начинаются с буквы Unicode или `_`, далее буквы, цифры, `_`. Ключевые слова с подчёркиваниями читаются целиком и сверяются с таблицей.

7. **Продолжение строк**: Выражение продолжается на следующей строке если:
   - строка заканчивается бинарным оператором, запятой, открывающей скобкой или `=>`
   - следующая строка начинается с `.`, `?.`, закрывающей скобки
   - Закрывающая `}` и продолжение на одной строке: `} а_чё_если (...) {`, `} а_нет {`, `} предъявил (Косяк к) {`, `} по_понятиям {`

8. **Контекстные ключевые слова**: `из`, `от`, `до`, `мимо`, `как` — ключевые только в своих конструкциях.

9. **Общак vs блок**: `{` после `=`, `(`, `,`, `:`, `[`, `=>`, `отдай` — это общак. Иначе — блок.

## Решения по семантике

10. **Сравнение чисел**: `1 == 1.0` истинно. Числа сравниваются по значению.

11. **Деление**: `/` всегда возвращает `дробь`. Целочисленное деление — функция `дели_целиком` из Версаль.

12. **Сложение строк**: В обычном режиме `текст + любое` — склейка с приведением. В режиме `мадмуазель` — ошибка E009.

13. **Истинность**: В обычном режиме ложны `неправда`, `пусто`, `0`, `0.0`, `""`. В `мадмуазель` условие обязано быть `логика`.

14. **Параметры по умолчанию**: Вычисляются при каждом вызове, могут ссылаться на константы и предыдущие параметры.

15. **Наследование конструктора**: Если у потомка нет конструктора, наследует родительский (аргументы передаются как есть).

16. **Модификаторы доступа**: `у_подъезда` (по умолчанию), `по_семейному`, `за_гаражами`. Нарушение — Косяк во время выполнения.

17. **Договорняки**: Проверка реализации всех методов при объявлении гопа (E005).

18. **na_потом**: Привязывается к ближайшему кортану (или файлу). Выполняется в обратном порядке (LIFO) при любом выходе. Выражение вычисляется в момент выхода. Ошибка в na_потом при летящем косяке заменяет его (решение: новый косяк побеждает, старый теряется — записано здесь).

19. **по_братски**: 
    - Целые: `доля_i = floor(сумма * вес_i / сумма_весов)`, остаток — первой цели. Значения прибавляются к текущим. Если источник — lvalue, обнуляется.
    - Дробь: точное деление, остатка нет.
    - W002 если сумма < числа целей.

20. **Асинхронность**: Кооперативный event loop, одно ядро. `сгоняй` — немедленный запуск до первого `подожди_пивас`. `братва` — параллельный запуск, результаты в исходном порядке. Первая ошибка отклоняет весь bratva.

21. **Виртуальное время**: Флаг `--без_пауз` / `GOP_VIRTUAL_TIME=1` — `перекур` продвигает виртуальные часы. Все тесты в этом режиме.

22. **События**: `слушай` — подписка, `кинь_клич` — синхронный вызов в порядке подписки. `отстань` — снимает все подписки. Нет подписчиков — W001. Исключение подписчика пробрасывается, остальные не вызываются.

23. **Буфера**: `новый Буфера(n)` — ёмкость n, переполнение = БуфераПолнаяКосяк. `по_кругу` — кольцевой. `Вот_это_буфера(n)` — ёмкость 2n. `чёткий_бампер(зад=k)` — лимит занятых мест k. Для кольцевого — Косяк.

24. **Сижка**: `сигара` — бесконечная (f(i) лениво). `папироска` — конечная (из кучки). `.затянись()` по иссякшей = Косяк R004. Итерация в `по_каждому`.

25. **Дворник/шухер/отбой**: `шухер(объект)` — сильная ссылка в реестре (счётчик). `отбой(объект)` — снимает одну. `шухер()` — `gc.disable()`, `отбой()` — `gc.enable()`. `Дворник.подмети()` — `gc.collect()`. `Дворник.шелухи_в_куче()` — недостижимых объектов. W003 если реестр не пуст в конце.

26. **Мадмуазель**: 
    - Включается файлом (`слыш ГопЛя 2.2 мадмуазель`) или перед `кортан`/`гоп`.
    - Все параметры и возврат обязаны иметь аннотации (E011).
    - Неявные приведения запрещены, кроме `целое → дробь`.
    - `пусто` только для `тип?` (E010).
    - Условия только `логика`.
    - `текст + число` = ошибка (E009).
    - Проверка статическая где типы известны, иначе рантайм с тем же сообщением.
    - Ошибки мадмуазель = ошибки компиляции (код 2, stdout пуст).

27. **Модули**: `позвать "Версаль"` — все публичные. `позвать "Погреб" как Подвал` — через префикс. `позвать { налей } из "ларёк"` — выборочно. Встроенные: Версаль, Погреб, Ларёк, Лотерея, Часы. Пользовательские: `файл.слыш` рядом, потом `./модули/`. Цикл импортов = ошибка. Модуль выполняется 1 раз, кэшируется. `Версаль` подключается автоматически только для `базарь` и `Косяк`.

28. **Стандартная библиотека (минимум)**:
    - Версаль: `перекур` (async), `шухер`, `отбой`, `Дворник`, `дели_целиком`, `спроси`, `корень`, `округли`, `модуль`, `в_текст`
    - Погреб: `прочитай`, `запиши`, `есть`
    - Ларёк: `достань` (async, HTTP GET, только с `--сеть`, иначе Косяк)
    - Лотерея: `случайное`, `выбери`, `зерно`
    - Часы: `сейчас`, `сегодня`

29. **Форматирование вывода** (раздел 6.4): 
    - целое: `42`
    - дробь: `0.5`, `1.0` (целая дробь с .0)
    - текст: как есть
    - логика: `правда` / `неправда`
    - пусто: `пусто`
    - кучка: `[2, 4]`, `[два, три, четыре]`, `[]`
    - общак: `{Жан: 100, Пьер: 250}`
    - объект: `<Подъезд>`
    - кортан: `<кортан имя>`
    - Гонец: `<гонец>`

30. **Коды возврата**: 0 — успех, 2 — ошибка компиляции/CLI, 13 — неперехваченный косяк, 1 — баг интерпретатора.

31. **Стандартные потоки**: Результат → stdout. Диагностика (ошибки, предупреждения, стек) → stderr.
