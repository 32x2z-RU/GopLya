# ГопЛя 2.2 «Ля'Мадмуазель» — Интерпретатор

Интерпретатор языка программирования ГопЛя версии 2.2.

## Установка

```bash
pip install -e .
```

## Использование

```bash
# Запуск программы
гоп запусти файл.слыш

# Проверка синтаксиса
гоп проверь файл.слыш

# Версия
гоп --версия

# Сборка (заглушка)
гоп собери файл.слыш
```

## Флаги

- `--без_пауз` — виртуальное время для тестов (перекур не спит, а продвигает виртуальные часы)
- `--сеть` — разрешить сетевые запросы (модуль Ларёк)

## Примеры

### Hello World
```goplya
слыш ГопЛя 2.2

базарь("Бонжур, епт!")
```

### Переменные и интерполяция
```goplya
слыш ГопЛя 2.2

семка кореш = "Серёга"
семка сколько = 30
базарь("Слышь, {кореш}, держи {сколько} семок!")
```

### Кортаны (функции)
```goplya
слыш ГопЛя 2.2

кортан квадрат(х) типа х * х
базарь(квадрат(5))  # 25
```

### ГОП (классы)
```goplya
слыш ГопЛя 2.2

гоп Кореш {
    у_подъезда семка имя: текст
    за_гаражами семка семки = 0

    кортан Кореш(имя, семки = 0) {
        сам.имя = имя
        сам.семки = семки
    }

    кортан дай(скока) {
        чё_если (скока > сам.семки) {
            кидай новый Косяк(сам.имя + ": у самого нет столько!")
        }
        сам.семки -= скока
        отдай скока
    }
}
```

### Асинхронность
```goplya
слыш ГопЛя 2.2
позвать { перекур } из "Версаль"

сгоняй кортан в_ларёк(что): текст {
    базарь("Побежал за {что}...")
    подожди_пивас перекур(1)
    отдай "{что} (холодное)"
}

сгоняй кортан главный() {
    семка всё = подожди_пивас братва([
        в_ларёк("семки"),
        в_ларёк("сухарики")
    ])
    базарь(всё)
}

главный()
```

### Ошибки
```goplya
слыш ГопЛя 2.2

кортан разделить(а, б) {
    чё_если (б == 0) {
        кидай новый Косяк("На ноль делить — не по-пацански")
    }
    отдай а / б
}

попробуй {
    базарь(разделить(10, 0))
} предъявил (Косяк к) {
    базарь("Предъявили: " + к.сообщение)
} по_понятиям {
    базарь("Разбор окончен")
}
```

### по_братски (дележ)
```goplya
слыш ГопЛя 2.2

семка общак = 100
семка жан = 0
семка пьер = 0
семка серёга = 0

по_братски (общак => жан, пьер, серёга)
базарь("{жан} / {пьер} / {серёга}")  # 34 / 33 / 33
```

### Буфера
```goplya
слыш ГопЛя 2.2

семка б = новый Буфера(3) по_кругу
б.положи("раз")
б.положи("два")
б.положи("три")
б.положи("четыре")
базарь(б.всё())  # [два, три, четыре]
```

### Сижка (ленивые потоки)
```goplya
слыш ГопЛя 2.2

семка п = Сижка(папироска, ["раз", "два", "три"])
грызи_пока (не_а п.бычок) {
    базарь(п.затянись())
}

семка с = Сижка(сигара, кортан(i) типа i * i)
базарь(с.затянись())  # 0
базарь(с.затянись())  # 1
базарь(с.затянись())  # 4
```

### События
```goplya
слыш ГопЛя 2.2

кортан пришёл(кто) {
    базарь("Бонжур, " + кто)
}

слушай "пришёл" => пришёл
кинь_клич "пришёл"("Мир")
```

### Мадмуазель (строгий режим)
```goplya
слыш ГопЛя 2.2 мадмуазель

мадмуазель кортан налей(кому: текст, сколько: дробь): текст {
    отдай "{кому}: {сколько} л"
}

# налей("Жан", "полведра")  # Ошибка компиляции!
```

## Архитектура

```
src/goplya/
├── cli.py              # CLI точка входа
├── lexer.py            # Лексер
├── parser.py           # Парсер (рекурсивный спуск)
├── analyzer.py         # Статический анализатор
├── interpreter.py      # Интерпретатор (tree-walking)
├── ast.py              # AST узлы
├── tokens.py           # Типы токенов
├── messages.py         # Каталог сообщений
├── runtime/
│   ├── values.py       # Значения (GopValue и наследники)
│   ├── errors.py       # Иерархия Косяк
│   ├── eventloop.py    # Event loop для async
│   ├── events.py       # События (кинь_клич/слушай)
│   ├── buffers.py      # Буфера
│   ├── streams.py      # Сижка
│   └── dvornik.py      # Дворник (GC API)
└── stdlib/             # Стандартные модули
    ├── versailles.py   # Ядро
    ├── pogreb.py       # Файлы
    ├── laryok.py       # Сеть
    ├── lotereya.py     # Случайность
    └── chasy.py        # Время
```

## Статус реализации

✅ Фаза 0: Каркас, CLI, hello world
✅ Фаза 1: Лексер, парсер, интерпретатор (выражения, переменные, управление, функции, коллекции, интерполяция)
✅ Фаза 2: Классы, наследование, интерфейсы, ошибки, на_потом, модули
✅ Фаза 3: Event loop, async/await, Гонец, братва, виртуальное время, события
🔄 Фаза 4: по_братски, Буфера, Сижка, шухер/отбой, Дворник (частично)
🔄 Фаза 5: Мадмуазель, статический анализ (частично)

## Известные проблемы

- Сижка (ленивые потоки) — есть баг в выполнении сигары
- Не все сообщения каталога покрыты тестами
- Некоторые граничные случаи в статическом анализе
