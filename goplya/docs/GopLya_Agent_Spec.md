# ГопЛя 2.2 «Ля'Мадмуазель» — спецификация для агента-реализатора

> Этот файл — единый источник правды для агента, который реализует интерпретатор языка **ГопЛя**.
> Рядом лежит `GopLya_Documentation.md` (пользовательское руководство). Если они расходятся,
> **приоритет у этого файла**, а расхождение записывается в `DECISIONS.md`.

---

## 0. Цель и объём

**Цель:** рабочий интерпретатор языка ГопЛя 2.2 с командой `гоп`, который запускает файлы `.слыш`,
проверяет синтаксис и выдаёт сообщения об ошибках в стиле языка.

| Этап | Что входит | Обязательность |
|---|---|---|
| MVP (фазы 1–3) | Ядро языка, классы, ошибки, модули, `на_потом`, асинхронность, события | Обязательно |
| Фича-пак (фаза 4) | `по_братски`, `Буфера`, `Сижка`, `шухер/отбой`, `Дворник` | Обязательно |
| Строгий режим (фаза 5) | `мадмуазель`, статические проверки, полный каталог сообщений | Обязательно |
| Бонус (фаза 6) | `гоп собери`, `бутыль` (заглушка), расширенная стандартная библиотека | Желательно |

**Вне объёма:** JIT, байткод-оптимизации, настоящий сборщик мусора (используем сборщик хоста),
IDE-плагины, форматтер.

## 1. Технологический выбор (рекомендации по умолчанию)

- **Язык реализации:** Python 3.11+, только стандартная библиотека (для тестов допустим `pytest`).
- **Архитектура:** ручной лексер → ручной рекурсивный парсер (нужен полный контроль над сообщениями об ошибках)
  → анализатор (области видимости, константы, `await` вне `сгоняй`, режим `мадмуазель`) → интерпретатор по дереву (tree-walking).
- **Кодировка:** UTF-8 везде. Принимать `\n` и `\r\n`. Файлы с BOM принимать.
- **Отклонения:** если агент хочет другой стек, он обязан сообщить об этом в первом ответе и записать в `DECISIONS.md`.

## 2. Лексика

### 2.1. Общие правила
- Программа — последовательность токенов. **Точек с запятой нет.** Конец оператора — конец строки, если выражение
  не продолжается (см. 2.5).
- Пробелы и табуляции между токенами игнорируются.
- Комментарии: `// до конца строки` и `/* ... */` (многострочные, не вкладываются).

### 2.2. Идентификаторы
- Начинаются с буквы Unicode или `_`, далее буквы, цифры, `_`.
- **Ключевые слова содержат подчёркивания** (`чё_если`, `от_бати`). Поэтому лексер читает идентификатор целиком
  и затем сверяет его с таблицей ключевых слов. Никакого «разрезания» по `_`.
- Регистр различается. `Сижка`, `Буфера`, `Вот_это_буфера`, `Косяк` — встроенные имена с заглавной буквы.

### 2.3. Литералы
| Литерал | Пример | Заметки |
|---|---|---|
| целое | `42`, `1_000` | Произвольная точность |
| дробь | `0.5`, `3.14` | Двойная точность; `.5` и `5.` недопустимы |
| текст | `"Ля'семки"` | Двойные кавычки, поддерживает интерполяцию |
| логика | `правда`, `неправда` | |
| пусто | `пусто` | Аналог null |
| кучка | `[1, 2, 3]` | |
| общак | `{ "Жан": 100 }` | В выражении после `=`, `(`, `,`, `:`, `[`, `=>`, `отдай`; иначе `{` — блок |

### 2.4. Строки и интерполяция
- Внутри строки `{выражение}` вычисляется и подставляется как текст (по правилам вывода из раздела 6.4).
- Экранирование: `\"`, `\\`, `\n`, `\t`, `\{`, `\}`.
- Вложенные фигурные скобки внутри `{...}` считаются по глубине. Строки внутри интерполяции разрешены.
- Пример: `"Итого: {сколько * 2}"`, `"У Жана: {жан.сколько()}"`.

### 2.5. Переносы строк и продолжение выражения
Оператор продолжается на следующей строке, если:
- строка заканчивается бинарным оператором, запятой, открывающей скобкой или `=>`;
- следующая строка начинается с `.`, `?.`, закрывающей скобки.

Закрывающая `}` и продолжение конструкции на одной строке допустимы: `} а_чё_если (...) {`, `} а_нет {`,
`} предъявил (Косяк к) {`, `} по_понятиям {`.

### 2.6. Операторы и пунктуация
`+ - * / % ** == != < > <= >= = += -= *= /= %= => ? ?. ?? : , . ( ) [ ] { }`
и словесные: `и_ещё`, `или_чё`, `не_а`. Символьные синонимы: `&&`, `||`, `!`.

### 2.7. Таблица ключевых слов (полная)

| Группа | Слова |
|---|---|
| Шапка | `слыш`, `ГопЛя` (контекстное), `мадмуазель` |
| Объявления | `пивас`, `семка`, `кортан`, `гоп`, `договорняк`, `вынеси` |
| ООП | `от_бати`, `по_договорняку`, `новый`, `сам`, `батя`, `у_подъезда`, `по_семейному`, `за_гаражами` |
| Управление | `чё_если`, `а_чё_если`, `а_нет`, `грызи_пока`, `по_каждому`, `хватит_епт`, `дальше_епт`, `отдай`, `типа` |
| Контекстные | `из`, `от`, `до`, `мимо`, `как` (ключевые только в своих конструкциях) |
| Ошибки | `попробуй`, `предъявил`, `по_понятиям`, `кидай` |
| Асинхронность | `сгоняй`, `подожди_пивас` |
| Модули | `позвать`, `вынеси`, `как`, `из` |
| Значения | `правда`, `неправда`, `пусто` |
| Операторы-слова | `и_ещё`, `или_чё`, `не_а` |
| Вывод | `базарь` |
| Фирменные | `по_братски`, `шухер`, `отбой`, `на_потом`, `кинь_клич`, `слушай`, `отстань`, `по_кругу` |
| Встроенные имена | `Косяк`, `БамперКосяк`, `Сижка`, `сигара`, `папироска`, `Буфера`, `Вот_это_буфера`, `Гонец`, `братва` (всегда доступны без импорта) |

Имена типов: `целое`, `дробь`, `текст`, `логика`, `пусто`, `кучка`, `общак`, `Гонец` и имена пользовательских гопов.
Суффикс `?` после типа (`текст?`) означает «допускает пусто».

## 3. Грамматика (EBNF, ориентир)

```ebnf
программа        = шапка , { объявление_верхнего } ;
шапка            = "слыш" , "ГопЛя" , ВЕРСИЯ , [ "мадмуазель" ] , КОНЕЦ_СТРОКИ ;

объявление_верхнего = [ "вынеси" ] , ( пивас | семка | кортан | гоп | договорняк )
                    | позвать | оператор ;

пивас            = "пивас" , ИМЯ , [ ":" , тип ] , "=" , выражение ;
семка            = "семка" , ИМЯ , [ ":" , тип ] , [ "=" , выражение ] ;

кортан           = [ "мадмуазель" ] , [ "сгоняй" ] , "кортан" , ИМЯ , параметры ,
                   [ ":" , тип ] , ( блок | "типа" , выражение ) ;
лямбда           = [ "сгоняй" ] , "кортан" , параметры , ( блок | "типа" , выражение ) ;
параметры        = "(" , [ параметр , { "," , параметр } ] , ")" ;
параметр         = ИМЯ , [ ":" , тип ] , [ "=" , выражение ] ;
тип              = ИМЯ , [ "?" ] ;

гоп              = [ "мадмуазель" ] , "гоп" , ИМЯ , [ "от_бати" , ИМЯ ] ,
                   [ "по_договорняку" , ИМЯ , { "," , ИМЯ } ] , "{" , { член } , "}" ;
член             = [ модификатор ] , ( поле | кортан ) ;
модификатор      = "у_подъезда" | "по_семейному" | "за_гаражами" ;
поле             = "семка" , ИМЯ , [ ":" , тип ] , [ "=" , выражение ] ;
договорняк       = "договорняк" , ИМЯ , "{" , { "кортан" , ИМЯ , параметры , [ ":" , тип ] } , "}" ;

позвать          = "позвать" , ( СТРОКА , [ "как" , ИМЯ ]
                               | "{" , ИМЯ , { "," , ИМЯ } , "}" , "из" , СТРОКА ) ;

оператор         = блок | пивас | семка | если | пока | для | попробуй | "отдай" , [ выражение ]
                 | "кидай" , выражение | "хватит_епт" | "дальше_епт"
                 | "на_потом" , ( оператор | блок )
                 | "базарь" , "(" , [ выражение , { "," , выражение } ] , ")"
                 | по_братски | слушай | кинь_клич | отстань
                 | присваивание | выражение ;

блок             = "{" , { оператор } , "}" ;
если             = "чё_если" , "(" , выражение , ")" , блок ,
                   { "а_чё_если" , "(" , выражение , ")" , блок } , [ "а_нет" , блок ] ;
пока             = "грызи_пока" , "(" , выражение , ")" , блок ;
для              = "по_каждому" , "(" , ИМЯ , ( "из" , выражение
                                              | "от" , выражение , ( "до" | "мимо" ) , выражение ) , ")" , блок ;
попробуй         = "попробуй" , блок ,
                   { "предъявил" , "(" , ИМЯ_ТИПА , ИМЯ , ")" , блок } ,
                   [ "по_понятиям" , блок ] ;

по_братски       = "по_братски" , "(" , выражение , "=>" , цель , { "," , цель } , ")" ;
цель             = lvalue , [ ":" , выражение ] ;                 (* вес доли *)
слушай           = "слушай" , СТРОКА , "=>" , выражение ;
кинь_клич        = "кинь_клич" , СТРОКА , [ аргументы ] ;
отстань          = "отстань" , СТРОКА ;

присваивание     = lvalue , ( "=" | "+=" | "-=" | "*=" | "/=" | "%=" ) , выражение ;
lvalue           = ИМЯ | выражение , "." , ИМЯ | выражение , "[" , выражение , "]" ;
```

### Выражения (приоритет от низшего к высшему)

| Ур. | Оператор | Ассоциативность |
|---|---|---|
| 1 | `? :` (тернарный) | правая |
| 2 | `??` | левая |
| 3 | `или_чё`, `\|\|` | левая |
| 4 | `и_ещё`, `&&` | левая |
| 5 | `==`, `!=` | левая |
| 6 | `<`, `>`, `<=`, `>=` | левая |
| 7 | `+`, `-` | левая |
| 8 | `*`, `/`, `%` | левая |
| 9 | унарные `-`, `не_а`, `!`, `подожди_пивас` | правая |
| 10 | `**` | правая |
| 11 | постфиксные: вызов `()`, индекс `[]`, `.`, `?.` | левая |

Первичные выражения: литералы, `ИМЯ`, `сам`, `батя`, `( выражение )`, `новый ИМЯ ( аргументы ) [ "по_кругу" ]`,
лямбда, кучка, общак.
Аргументы: позиционные, затем именованные `имя = выражение` (`налей("Жан", пиво = правда)`).
Присваивание — **оператор**, не выражение: поэтому `имя = значение` внутри скобок вызова однозначно читается как именованный аргумент.

## 4. Семантика ядра

### 4.1. Значения и типы
- `целое` (произвольная точность), `дробь`, `текст`, `логика`, `пусто`, `кучка`, `общак`, функции (кортаны), объекты гопов, `Гонец`.
- `==` сравнивает числа по значению (`1 == 1.0` истинно), текст по значению, кучки и общаки поэлементно, объекты по ссылке.
- `/` всегда возвращает `дробь`. Целочисленное деление: функция `дели_целиком(a, b)` из `Версаль`.
- `+` : число+число — сложение; текст+текст — склейка; **в обычном режиме** текст + любое значение — склейка с приведением
  (так делают примеры из руководства: `"У Серёги: " + серёга.сколько()`). В режиме `мадмуазель` — ошибка.
- Истинность в условиях (обычный режим): ложны `неправда`, `пусто`, `0`, `0.0`, `""`. Остальное истинно.
  В режиме `мадмуазель` условие обязано быть `логика`.

### 4.2. Переменные и константы
- `пивас` — неизменяемая привязка. Повторное присваивание — ошибка компиляции `E003`.
- `семка` — изменяемая. Область видимости блочная; замыкания захватывают окружение по ссылке.
- Необъявленное имя — `E004`.
- Необязательная аннотация типа `семка имя: текст = "…"`. В обычном режиме несоответствие инициализатора аннотации — `E007`
  (проверяется статически, где тип выражения известен, иначе при выполнении).

### 4.3. Кортаны
- Параметры по умолчанию вычисляются **при вызове**, могут ссылаться на константы и предыдущие параметры.
- Именованные аргументы после позиционных. Ошибки: неизвестное имя, дубликат, пропущенный обязательный аргумент — `Косяк`.
- `типа` задаёт тело-выражение: `кортан квадрат(х) типа х * х`.
- Лямбда: `кортан(х) типа х * 2` или `кортан(х) { отдай х * 2 }`.
- Функция без `отдай` возвращает `пусто`.
- Кортаны — значения первого класса, замыкания работают.

### 4.4. Циклы
- `грызи_пока (усл) { … }`.
- `по_каждому (x из коллекция)` обходит `кучка`, ключи `общака` (порядок вставки), `Сижка`, `Буфера` (от старого к новому).
- `по_каждому (i от a до b)` — **включительно**; `от a мимо b` — **не включая b**. Шаг всегда `+1`; при `a > b` цикл пуст.
- `хватит_епт` и `дальше_епт` действуют на ближайший цикл.

### 4.5. Коллекции (обязательный минимум)
| Объект | Члены |
|---|---|
| кучка | `[i]` (с нуля), `.длина` (свойство), `.добавь(x)`, `.выкини(i)` (удаляет и возвращает), `.перемешай()` (на месте), `.самая_большая()`, `.отбери(f)` (filter), `.возьми(n)` недоступен у кучки (он у `Сижка`) |
| общак | `[ключ]` чтение/запись (отсутствующий ключ при чтении — `пусто`), `.ключи` (свойство, кучка), `.длина` |
| текст | `.длина` |

Любой другой метод или свойство — на усмотрение агента с записью в `DECISIONS.md` (`.карта`, `.свернуть`, `.есть`, …).
Выход индекса за границы — `Косяк` («Нет такого места в кучке, мон ами»).

### 4.6. Безопасная навигация
- `а ?? б` — `б`, если `а` равно `пусто`.
- `а?.б.в` — **короткое замыкание на всю цепочку**: если `а` пусто, результат `пусто`, остальная цепочка не вычисляется.

### 4.7. Классы (`гоп`)
- Конструктор — кортан **с именем гопа**. Если у потомка конструктора нет, он наследует конструктор родителя (аргументы передаются как есть).
- `сам` — текущий объект, `батя.метод(...)` — вызов метода родителя, `батя(...)` внутри конструктора — вызов конструктора родителя.
- Поля с инициализаторами инициализируются перед телом конструктора, в порядке объявления, родительские раньше.
- Модификаторы: `у_подъезда` (по умолчанию, публичный), `по_семейному` (класс и потомки), `за_гаражами` (только сам класс).
  Нарушение доступа — `Косяк` во время выполнения с сообщением «Это за гаражами, мон ами».
- Множественного наследования нет; интерфейсов (`договорняк`) может быть несколько.
- Гоп, заявивший `по_договорняку Х`, обязан реализовать все кортаны `Х` (проверка при объявлении, `E005`).
- Переопределение метода: тот же имя; сигнатура сверяется только по числу параметров.

### 4.8. Ошибки (`Косяк`)
- Иерархия: `Косяк` ← `БамперКосяк`, `БуфераПолнаяКосяк`, `КосякТипа`, `КосякИндекса`, любые пользовательские.
- У каждого экземпляра: свойство `.сообщение` (текст). Конструктор `Косяк(сообщение)`.
- `кидай выражение` — выражение обязано быть экземпляром `Косяк` или потомка, иначе `КосякТипа`.
- `попробуй … предъявил (Тип имя) … по_понятиям` — предъявил подбирается по порядку, подходит `instanceof`;
  `по_понятиям` выполняется всегда (в том числе при `отдай`/`кидай`/`хватит_епт` внутри блока).
- Неперехваченный косяк: печать в stderr `Меня предъявили, а я не готов: <сообщение>` плюс строки стека
  (`  в кортане «имя», строка N`), код возврата **13**.
- Деление на ноль, ошибки типов времени выполнения, выход за границы — встроенные `Косяк` с гоп-текстами.

### 4.9. `на_потом` (отложенное действие)
- Привязывается к ближайшему **кортану** (или к файлу, если на верхнем уровне).
- Выполняется при **любом** выходе из кортана: нормальном, через `отдай`, через `кидай`.
- Несколько `на_потом` исполняются в **обратном порядке** (LIFO).
- Выражение внутри вычисляется **в момент выхода** (не при регистрации), в окружении кортана.
- Ошибка внутри `на_потом` при уже летящем косяке заменяет его (как в `finally`); решение записать в `DECISIONS.md`.

### 4.10. `по_братски` (дележ)
Синтаксис: `по_братски (источник => цель1, цель2, …)` или с долями: `цель1: 2, цель2: 1`.

Правила для **целых**:
1. Если веса не указаны, у всех вес 1.
2. `доля_i = floor(сумма * вес_i / сумма_весов)`.
3. Остаток `сумма − Σ доля_i` добавляется **первой цели**.
4. Каждая цель **увеличивается** на свою долю (прибавление к текущему значению, значения не затираются).
5. Если источник — переменная (lvalue), после дележа в неё записывается `0`. Если выражение/литерал — ничего не меняется.
6. Если `сумма < числа целей`: часть целей получит 0, выводится предупреждение `W002`.

Правила для **дробей**: `доля_i = сумма * вес_i / сумма_весов`, остатка нет.
Ошибки: цель не число (или не lvalue) — `КосякТипа`; нулевая сумма весов — `Косяк`.

Проверка: `100 => жан, пьер, серёга` даёт `34, 33, 33`; `100 => старший: 2, младший: 1` даёт `67, 33`.

### 4.11. Асинхронность
- Модель: **один поток, кооперативный планировщик** (event loop), без реальных потоков.
- `сгоняй кортан` — асинхронный кортан. Вызов **немедленно начинает выполнение** и возвращает `Гонец`;
  выполнение идёт до первого `подожди_пивас` (как у корутин JavaScript).
- `подожди_пивас х` разрешён только внутри `сгоняй`-кортана (`E006` иначе). Приостанавливает текущую задачу, пока `х`-`Гонец` не завершится.
  Если `х` не `Гонец`, возвращает `х` как есть.
- `братва([г1, г2, …])` — возвращает `Гонец`, завершающийся, когда завершатся все; результат — кучка результатов **в исходном порядке**.
  Первая ошибка отклоняет весь `братва`.
- `перекур(сек)` из `Версаль` — асинхронный кортан: засыпает на `сек` секунд.
- Вызов `сгоняй`-кортана на верхнем уровне без `подожди_пивас` разрешён (как в примерах: `главный()`).
  Программа **завершается, когда выполнены все задачи** (после последнего оператора файла планировщик догоняет всё остальное).
- Неперехваченный косяк внутри `Гонец`, который никто не ждёт, — выводится как неперехваченный в конце, код 13.
- **Виртуальное время:** флаг `--без_пауз` (и переменная окружения `GOP_VIRTUAL_TIME=1`) заставляет `перекур` продвигать виртуальные часы
  вместо реального сна. Все тесты работают в этом режиме; порядок событий должен быть тот же, что и в реальном времени.

### 4.12. События
- `слушай "имя" => f` — подписывает `f` (имя кортана, лямбда или любой вызываемый) на событие.
  Один и тот же вызываемый можно подписать несколько раз — он вызовется столько же раз.
- `кинь_клич "имя"(арг, …)` — синхронно вызывает подписчиков **в порядке подписки**. Если подписчик вернул `Гонец`, он запускается, но не ожидается.
- `отстань "имя"` — снимает **все** подписки на это имя.
- Нет подписчиков: предупреждение `W001` (в stderr), выполнение продолжается.
- Исключение подписчика пробрасывается из `кинь_клич`, остальные подписчики не вызываются.

### 4.13. `Буфера`
| Конструкция | Поведение |
|---|---|
| `новый Буфера(n)` | Ёмкость `n`. Переполнение — `БуфераПолнаяКосяк("Буфера полная")` |
| `новый Буфера(n) по_кругу` | Кольцевой: при переполнении вытесняется самый старый элемент |
| `новый Вот_это_буфера(n)` | Ёмкость **`2·n`** («с запасом»). Допускает `по_кругу` |
| `.положи(x)` | Добавляет в конец |
| `.всё()` | Возвращает кучку элементов от старого к новому |
| `.ёмкость`, `.длина` | Свойства |
| `.чёткий_бампер(зад = k)` | Ограничивает **число занятых мест** значением `k` (`k ≤ ёмкость`). Попытка положить элемент №`k+1` — `БамперКосяк("Бабах! Чёткий бампер не пропустил: зад на позиции k")` |

Для кольцевого буфера `.чёткий_бампер` — `Косяк` («Кольцу бампер не нужен»).
Поддерживается итерация в `по_каждому`.

### 4.14. `Сижка`
Ленивый поток значений.

| Конструктор | Поведение |
|---|---|
| `Сижка(сигара, f)` | Бесконечный. `f(i)` вызывается лениво для `i = 0, 1, 2, …`, **ровно один раз на затяжку** |
| `Сижка(папироска, кучка)` | Конечный. Отдаёт элементы кучки по порядку, потом становится бычком |

Члены: `.затянись()` — следующее значение; `.бычок` — `правда`, когда поток иссяк (у сигары всегда `неправда`);
`.возьми(n)` — кучка из следующих `n` значений (у папиросы может вернуть меньше).
`.затянись()` по иссякшей — `Косяк("Бычок. Тянуть нечего.")`. Поддерживается итерация в `по_каждому`
(для сигары цикл бесконечен, нужен `хватит_епт`). `сигара` и `папироска` — встроенные константы-метки.

### 4.15. `Дворник`, `шухер`, `отбой`
Настоящего GC не пишем, используем сборщик хоста и моделируем API:
- `шухер(объект)` — сохраняет сильную ссылку в реестре «заначек»; объект не будет собран. Повторный `шухер` того же объекта — счётчик.
- `отбой(объект)` — снимает одну ссылку. `шухер()` без аргументов — приостанавливает сборщик (`gc.disable()`), `отбой()` — возобновляет.
- `Дворник.подмети()` — принудительная сборка (`gc.collect()`); `Дворник.шелухи_в_куче()` — число недостижимых объектов, найденных последней сборкой (или `0`).
- При завершении программы, если реестр заначек не пуст, — предупреждение `W003`.
- Все эти имена импортируются из `Версаль`.

### 4.16. Режим `мадмуазель` (строгий)
Включается: `слыш ГопЛя 2.2 мадмуазель` (на весь файл) или словом `мадмуазель` перед `кортан`/`гоп` (на эту область).

Правила строгого режима:
1. Все параметры и возвращаемое значение кортана обязаны иметь аннотации типов (иначе `E011`).
2. Никаких неявных приведений. Единственное разрешённое — расширение `целое → дробь`.
3. `пусто` допустимо только для типов с `?` (`текст?`). Иначе `E010`.
4. Условия `чё_если`/`грызи_пока` — только `логика`.
5. Операция `текст + число` и подобные — ошибка типов `E009`.
6. Проверка выполняется **статически**, где типы известны (литералы, аннотированные переменные, вызовы аннотированных кортанов);
   где статически не выяснить, проверка переносится на время выполнения с тем же сообщением.
7. Ошибки строгого режима — ошибки **компиляции**: программа не запускается, stdout пуст, код возврата 2.

Для сообщения `E009` форма типа в родительном падеже:
`целое → целого`, `дробь → дроби`, `текст → текста`, `логика → логики`, `пусто → пусто`, `кучка → кучки`, `общак → общака`, `гоп Х → «Х»`.

### 4.17. Модули
- `позвать "Версаль"` — подключает все публичные имена. `позвать "Погреб" как Подвал` — доступ через `Подвал.имя`.
  `позвать { налей } из "ларёк"` — выборочно.
- Встроенные модули (регистр важен): `Версаль`, `Погреб`, `Ларёк`, `Лотерея`, `Часы`. Остальные имена — пользовательские файлы:
  `"ларёк"` → `ларёк.слыш` рядом с вызывающим файлом (затем в `./модули/`). Имя встроенного модуля имеет приоритет.
- Публично только то, что помечено `вынеси`. Цикл импортов — ошибка с гоп-текстом (формулировка на усмотрение агента).
- Модуль выполняется один раз; результат кэшируется.
- Побочный эффект `Версаль` подключается автоматически только для **`базарь`** и `Косяк`. Остальное (`перекур`, `шухер`, …) — через `позвать`.

### 6.1. Каталог сообщений (источник — `messages.py`)

Формат ошибки компиляции: **`Ошибка: <фраза> Строка N.`** в stderr. Предупреждения: **`Предупреждение: <фраза> Строка N.`**

|---|---|---|---|

| E002 | компиляция | Файл кончился, блок не закрыт | `Слышь, ты чё, не договорил!` |
| E003 | компиляция | Присваивание `пивас` | `Слышь, это пивас, его уже налили.` |
| E004 | компиляция | Необъявленное имя | `Кто такой «{имя}»? Я его не знаю.` |

| E009 | компиляция (мадмуазель) | Несовпадение типов | `Мадмуазель в шоке: «{получено}» вместо «{ожидалось_род}». Так не делают.` |

| E012 | компиляция | Версия файла выше версии интерпретатора | `Этот файл из будущего: нужна ГопЛя {версия}.` ★ |

| R001 | выполнение | Неперехваченный косяк | `Меня предъявили, а я не готов: {сообщение}` |
| R002 | выполнение | `Буфера` переполнена | `Буфера полная` |
| R003 | выполнение | Бампер | `Бабах! Чёткий бампер не пропустил: зад на позиции {k}` |

| R007 | выполнение | Индекс вне границ | `Нет такого места в кучке, мон ами.` ★ |

### 6.2. Коды возврата
`0` — успех; `2` — ошибка компиляции или CLI; `13` — неперехваченный косяк; `1` — внутренняя ошибка интерпретатора (баг).

### 6.3. Потоки
Результат программы → **stdout**. Предупреждения, ошибки и стек → **stderr**. Тесты сверяют stdout и код, а stderr — по подстроке.

### 6.4. Форматирование значений при выводе и интерполяции
| Значение | Вывод |

| текст | как есть, без кавычек (в том числе внутри кучек) |
| логика | `правда` / `неправда` |
| пусто | `пусто` |
| кучка | `[2, 4]`, `[два, три, четыре]`, пустая — `[]` |
