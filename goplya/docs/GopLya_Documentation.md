## 1. Предисловие: зачем это всё, епт

Мир программирования давно поделён на два лагеря: тех, кто пишет скучные строгие языки в галстуках, и тех, кто пишет на чём попало, сидя на корточках. **ГопЛя** — первый язык, который примиряет обоих. Он родился в тени фамильного шато, где юный наследник, вместо того чтобы изучать фехтование, изучал лузгание семок и компиляторы.

Философия языка укладывается в три постулата:

**1. Всё есть гоп.** Любая сущность — объект. Даже пустота. Особенно пустота — она у нас называется `пусто`.

**2. Пивас неизменен.** Константа, однажды налитая, не доливается и не выливается. Если очень хочется — заведи новую бутылку.

**3. Семки грызи, шелуху убирай.** Переменные меняются свободно, а за мусором следит Дворник. Ты его не видишь, но он есть, и он всё помнит.

> 🏰 **Факт из Версаля**
>
> Название «ГопЛя» произошло от слияния «гоп» (ГОП — Гоп-Ориентированное Программирование) и французского артикля «Ля», который автор вставил везде, где мог, и ещё в пару мест, где не мог.

> 💡 **Совет от бати**
>
> Оглавление собирается автоматически. Если номер страницы не совпал с реальностью — это не баг, это фича: так в Версале заблудились ещё три герцога.

### Для кого эта документация

Для тебя, мон ами. Если ты умеешь писать `если/иначе` на любом другом языке, ты уже почти готов. Если не умеешь — тоже заходи, у нас тут без дресс-кода, только пивной код.

## 2. Установка и первый запуск

Ставится ГопЛя через собственный пакетный менеджер **«бутыль»**. Название выбрано потому, что пакеты в нём называются «налитыми», а установка — «открыть». Звучит естественно, если выпить.

```
# Открыть бутыль с компилятором
бутыль открой гоп

# Проверить, что налилось
гоп --версия
```

*Вывод:*

```text
ГопЛя 2.2 «Ля'Мадмуазель». Бонжур, епт! Дворник на посту.
```

### Первая программа

Создай файл `шато.слыш` и напиши внутрь:

```
слыш ГопЛя 2.2

базарь("Бонжур, епт!")
```

Запусти командой `гоп запусти шато.слыш`. Первая строка `слыш ГопЛя 2.2` — это «шапка» файла. Она обязательна: без неё компилятор обидится, потому что не любит, когда с ним не здороваются.

### Команды командной строки

| Команда | Что делает |
|---|---|
| `гоп запусти файл.слыш` | Запускает программу. Быстро, как слух в подъезде. |
| `гоп собери файл.слыш` | Собирает исполняемый файл. Результат называется «бочка». |
| `гоп проверь файл.слыш` | Проверяет синтаксис, ничего не запуская. «Поговорить без рук». |
| `бутыль открой пакет` | Устанавливает пакет. |
| `бутыль допей пакет` | Удаляет пакет. Тару сдавать не нужно. |
| `гоп --версия` | Показывает версию и настроение Дворника. |

## 3. Пивас и семки: переменные и типы

В ГопЛе два способа хранить значение. `пивас` — константа: налил и закрыл. `семка` — переменная: грызи, плюй, меняй, как душе угодно.

```
пивас ЛЯ_БУТЫЛКА = 0.5            // литров. Не трожь.
семка кол_во_семок = 100          // грызи на здоровье
семка имя: текст = "Жан-Клод"     // тип можно указать явно
кол_во_семок -= 7                 // схрумкал немного

ЛЯ_БУТЫЛКА = 1.0                  // КОСЯК: пивас менять нельзя!
```

> ⚠️ **Внимание, косяк!**
>
> Попытка переприсвоить `пивас` вызовет ошибку компиляции *«Слышь, это пивас, его уже налили»*. Если очень надо — заведи новую константу. Пиво бесплатное, имена — тоже.

### Типы данных

| Тип | Что это | Пример |
|---|---|---|
| `целое` | Целое число | `42` |
| `дробь` | Число с запятой (точкой, мы же не в Париже на лавочке) | `0.5` |
| `текст` | Строка | `"Ля'семки"` |
| `логика` | Принимает `правда` или `неправда` | `правда` |
| `пусто` | Ничего. Бутылка есть, пива нет | `пусто` |
| `кучка` | Список (массив) | `["раз", "два"]` |
| `общак` | Словарь «ключ — значение» | `{"Жан": 100}` |

### Строки и интерполяция

Внутри строки можно подставлять значения через фигурные скобки. Это называется **«подсолнечная подстановка»**:

```
семка кореш = "Серёга"
семка сколько = 30
базарь("Слышь, {кореш}, держи {сколько} семок!")
базарь("Итого с учётом батиного вклада: {сколько * 2}")
```

*Вывод:*

```text
Слышь, Серёга, держи 30 семок!
Итого с учётом батиного вклада: 60
```

### Кучки и общаки

```
семка семки = ["подсолнух", "тыква", "арбуз"]
семки.добавь("кедр")              // в конец кучки
базарь(семки.длина)               // 4
базарь(семки[0])                  // подсолнух (счёт с нуля, как у приличных людей)

семка общак = { "Жан": 100, "Пьер": 250 }
общак["Серёга"] = 0               // новый участник, пока без вложений
по_каждому (кто из общак.ключи) {
    базарь(кто + " вложил " + общак[кто])
}
```

> 💡 **Совет от бати**
>
> У кучки есть удобные методы: `.добавь()`, `.выкини()`, `.перемешай()` и `.самая_большая()`. Последний, правда, возвращает самую большую семку, а не самое большое достижение.

## 4. Операторы

Арифметика в ГопЛе привычная, а вот логика говорит по-пацански. Словесные и символьные формы равноправны: используй те, что ближе твоей душе и уровню трезвости.

| Оператор | Значение | Комментарий |
|---|---|---|
| `+  -  *  /  %` | Арифметика | Как в школе, только без двоек |
| `**` | Степень | «Сколько семок в подсолнухе» |
| `==   !=` | Равно / не равно | Сравнение по понятиям |
| `и_ещё  (&&)` | Логическое И | «И ещё вот это» |
| `или_чё  (\|\|)` | Логическое ИЛИ | «Или чё, не слышно?» |
| `не_а  (!)` | Логическое НЕ | Отрицание. Отнекиваемся красиво |
| `??` | Значение по умолчанию | Если слева `пусто`, берём справа |
| `?.` | Аккуратный доступ | Не падает, если объект `пусто` |
| `? :` | Тернарный оператор | Коротко и ясно, как «да/нет» |

```
семка пиво_есть = правда
семка настроение = пиво_есть ? "кайф" : "тоска"

семка кошелёк = пусто
семка налик = кошелёк ?? 0                  // если пусто — нолик
семка длина = кошелёк?.монеты.длина         // не упадёт, вернёт пусто

чё_если (пиво_есть и_ещё не_а в_ларьке_очередь) {
    базарь("Идём, епт")
}
```

## 5. Условия и циклы

### Чё если: ветвления

```
семка семок = 12

чё_если (семок > 50) {
    базарь("Жить можно")
} а_чё_если (семок > 0) {
    базарь("Экономим, мон ами")
} а_нет {
    базарь("Пусто. Пошли в ларёк")
}
```

Ключевое слово `а_чё_если` заменяет `else if` и экономит нервы. Количество веток ограничено только твоим терпением и размером шато.

### Грызи пока: цикл while

```
семка семки = 10

грызи_пока (семки > 0) {
    семки -= 1
    чё_если (семки == 7) { дальше_епт }   // пропускаем «несчастливую»
    чё_если (семки == 2) { хватит_епт }   // выходим из цикла
    базарь("Осталось: {семки}")
}
```

### По каждому: цикл for

```
по_каждому (кореш из ["Жан", "Пьер", "Серёга"]) {
    базарь("Бонжур, " + кореш)
}

по_каждому (i от 1 до 5) {         // «до» — включительно
    базарь(i)
}

по_каждому (i от 0 мимо 3) {       // «мимо» — не включая
    базарь(i)                      // 0, 1, 2
}
```

> 🏰 **Факт из Версаля**
>
> `до` и `мимо` возникли из философского спора: «Дойдёт ли пацан до подъезда или пройдёт мимо?». Консилиум постановил: бывает и так, и так.

Сигнал `хватит_епт` прерывает цикл, а `дальше_епт` переходит к следующей итерации. Бесконечный цикл делается через `грызи_пока (правда)`. Выход — только по `хватит_епт` или по звонку мамы.

## 6. Кортаны: функции

Функция в ГопЛе называется **кортан**. Кортан принимает аргументы, делает дела и **отдаёт** результат. Что ни отдал — то пропало, как семки у друга.

```
кортан сложи(а: целое, б: целое): целое {
    отдай а + б
}

// стрелочная запись через «типа»
кортан квадрат(х) типа х * х

// значения по умолчанию
кортан налей(кому, сколько = ЛЯ_БУТЫЛКА) {
    базарь("Налил {кому} ровно {сколько} л")
}

налей("Жану")             // Налил Жану ровно 0.5 л
налей("Пьеру", 1.5)       // Налил Пьеру ровно 1.5 л
```

### Анонимные кортаны (лямбды)

Кортан можно создать на лету и сунуть в переменную, как семку в карман:

```
семка удвой = кортан(х) типа х * 2
базарь(удвой(21))                              // 42

семка кучка = [1, 2, 3, 4]
семка чётные = кучка.отбери(кортан(х) типа х % 2 == 0)
базарь(чётные)                                 // [2, 4]
```

> 💡 **Совет от бати**
>
> Кортан может возвращать другой кортан. Так делают замыкания: внутренняя функция помнит всё, что видела снаружи — как соседка тётя Люся, только полезная.

### Именованные аргументы

```
кортан угости(кореш, семки = 10, пиво = неправда) { /* ... */ }

угости("Жан", пиво = правда)       // семки по умолчанию, пиво включено
```

## 7. ГОП: Гоп-Ориентированное Программирование

Это сердце языка. Всё строится вокруг **гопов** (классов). Гоп описывает, как устроен тип объекта: какие у него семки (поля) и какие кортаны (методы). Создаётся объект через `новый`.

### Модификаторы доступа

| Слово | Аналог | Кто видит |
|---|---|---|
| `у_подъезда` | public | Все, кто проходит мимо |
| `по_семейному` | protected | Свой гоп и наследники («от_бати») |
| `за_гаражами` | private | Только сам гоп. Вход строго по пропускам |

### Класс и наследование

```
гоп Шато {
    у_подъезда семка название: текст
    за_гаражами семка погреб = 42            // бутылок

    кортан Шато(название) {                  // конструктор = имя гопа
        сам.название = название
    }

    кортан открой_погреб() {
        отдай сам.погреб
    }
}

гоп Подъезд от_бати Шато {
    кортан открой_погреб() {                 // переопределяем
        базарь("Батя разрешил, заходи")
        отдай батя.открой_погреб()           // вызов родителя
    }
}

семка хата = новый Подъезд("Ля'Хрущёвка")
базарь(хата.открой_погреб())
```

*Вывод:*

```text
Батя разрешил, заходи
42
```

Три важных слова: `сам` (этот объект, this), `батя` (родитель, super), `от_бати` (наследование). Множественного наследования нет: у одного человека один батя, и это правильно.

### Договорняки (интерфейсы)

Договорняк — это обещание: «любой гоп, который его принял, обязан уметь вот это». Нарушил договорняк — компилятор вежливо, но твёрдо поговорит по душам.

```
договорняк Угощающий {
    кортан угости(кореш, сколько)
}

гоп Жан от_бати Шато по_договорняку Угощающий {
    кортан угости(кореш, сколько) {
        базарь("Жан угощает {кореш}: {сколько} шт.")
    }
}
```

> ⚠️ **Внимание, косяк!**
>
> Если гоп заявил `по_договорняку`, но не реализовал нужный кортан, получишь: *«Не по понятиям: обещал угостить, а кортана нет»*. Исправляется быстрее, чем извинения.

## 8. Асинхронность: «сгоняй» и «подожди пивас»

Некоторые дела делаются не сразу: сходить в ларёк, дождаться автобуса, получить ответ от сервера. Чтобы не стоять столбом, в ГопЛе 2.0 есть асинхронность.

| Слово | Что значит | Аналог |
|---|---|---|
| `сгоняй` | Помечает кортан как асинхронный | async |
| `подожди_пивас` | Дождаться результата, не блокируя остальных | await |
| `гонец` | Обещание: «я сгонял, вот что вернул» | Promise |
| `братва` | Запустить несколько дел вместе и дождаться всех | Promise.all |
| `перекур(сек)` | Пауза в секундах (из модуля Версаль) | sleep |

```
слыш ГопЛя 2.2
позвать { перекур } из "Версаль"

сгоняй кортан в_ларёк(что): текст {
    базарь("Побежал за {что}...")
    подожди_пивас перекур(2)
    отдай "{что} (холодное)"
}

сгоняй кортан главный() {
    // по очереди
    семка пиво = подожди_пивас в_ларёк("Ля'пивас")
    базарь(пиво)

    // сразу в два ларька, по-братски
    семка всё = подожди_пивас братва([
        в_ларёк("семки"),
        в_ларёк("сухарики")
    ])
    базарь(всё)
}

главный()
```

*Вывод:*

```text
Побежал за Ля'пивас...
Ля'пивас (холодное)
Побежал за семки...
Побежал за сухарики...
[семки (холодное), сухарики (холодное)]
```

> 💡 **Совет от бати**
>
> Первый заход шёл два «перекура» подряд, а «братва» отработала вдвое быстрее, потому что бежали параллельно. Мораль: в жизни и в коде вместе веселее и быстрее.

> ⚠️ **Внимание, косяк!**
>
> `подожди_пивас` можно использовать только внутри `сгоняй`-кортана. Ждать пиво на пустом месте компилятор запрещает: *«Ты не в ларьке, чего ждёшь?»*

## 9. Ошибки: «предъявил» и «по понятиям»

В ГопЛе ошибки называются **косяками**. Бросается косяк словом `кидай`. Ловится блоком `предъявил`. Блок `по_понятиям` (finally) выполнится в любом случае — потому что по понятиям надо, а не потому что хочется.

```
кортан разделить(а, б) {
    чё_если (б == 0) {
        кидай новый Косяк("На ноль делить — не по-пацански")
    }
    отдай а / б
}

попробуй {
    семка х = разделить(10, 0)
    базарь(х)
} предъявил (Косяк к) {
    базарь("Предъявили: " + к.сообщение)
} по_понятиям {
    базарь("Ля'пивас допит, разбор окончен")
}
```

*Вывод:*

```text
Предъявили: На ноль делить — не по-пацански
Ля'пивас допит, разбор окончен
```

### Свои косяки

```
гоп НетСемок от_бати Косяк {
    кортан НетСемок(кто) {
        батя("{кто}: семок нет, епт")
    }
}

кидай новый НетСемок("Серёга")
```

> 🏰 **Факт из Версаля**
>
> Если косяк не пойман, программа завершается с кодом **13** и сообщением *«Меня предъявили, а я не готов»*. Код 13 выбран в честь несчастливого числа семок в пакете.

## 10. Модули и Дворник

### Модули

Код делится на файлы, файлы подключаются через `позвать`, а выставляется наружу всё, что помечено `вынеси`. Остальное остаётся в погребе.

```
// файл ларёк.слыш
вынеси кортан налей(сколько) { отдай "налито {сколько} л" }
кортан тайная_полка() { /* не видно снаружи */ }

// файл главный.слыш
позвать "Версаль"                          // подключить целиком
позвать "Погреб" как Подвал                // с псевдонимом
позвать { налей } из "ларёк"               // выборочно
```

### Стандартные модули

| Модуль | Что внутри |
|---|---|
| `Версаль` | Ядро: вывод, ввод, паузы, математика. Подключается автоматически, как охрана. |
| `Погреб` | Работа с файлами: читать, писать, прятать от жены. |
| `Ларёк` | Сеть и HTTP. «Сходить на сервер и вернуться с ответом». |
| `Лотерея` | Случайные числа. Не ко всему применимо, но вдруг повезёт. |
| `Часы` | Время и даты. Включая «после обеда» и «до рассвета». |

### Дворник: сборщик мусора

Память в ГопЛе освобождает **Дворник**. Он ходит по двору программы, подметает шелуху от семок, то есть объекты, на которые больше никто не ссылается. Дворник работает по собственному графику и о нём можно не думать. Но можно и поздороваться:

```
позвать { Дворник } из "Версаль"

Дворник.подмети()                  // принудительная уборка
базарь(Дворник.шелухи_в_куче())    // сколько мусора лежит
```

> ⚠️ **Внимание, косяк!**
>
> Не вызывай `Дворник.подмети()` в цикле. Дворник обидится, уйдёт на перекур, и вся программа будет стоять, пока он не вернётся. Профсоюз у них сильный.

## 11. Сообщения компилятора

Компилятор ГопЛи разговаривает с программистом по-человечески. Иногда слишком по-человечески. Ниже — самые частые реплики и что они значат на самом деле.

| Сообщение | Что на самом деле |
|---|---|
| Ошибка: скобку потерял, дружище. Строка 7. | Незакрытая скобка. Найди пару и верни. |
| Слышь, ты чё, не договорил! | Не закрыт блок `{ }` в конце файла. |
| Слышь, это пивас, его уже налили. | Попытка изменить константу. |
| Кто такой «кореш»? Я его не знаю. | Использована необъявленная переменная. |
| Не по понятиям: обещал угостить, а кортана нет. | Гоп не реализовал метод договорняка. |
| Ты не в ларьке, чего ждёшь? | `подожди_пивас` вне `сгоняй`-кортана. |
| Тип не тот. Просили пивас, принесли семку. | Несовпадение типов. |
| Семок на всех не хватит, мон ами. | `по_братски`: делить нечего, каждому достанется ноль. |
| Заначка без отбоя: Дворник в обиде. | `шухер` без парного `отбой` (утечка памяти). |
| Мадмуазель в шоке: «текст» вместо «дроби». Так не делают. | Нарушение типов в режиме `мадмуазель`. |
| Бабах! Чёткий бампер не пропустил. | Запись за пределы, заданные `чёткий_бампер(зад)`. |
| Бычок. Тянуть нечего. | `.затянись()` у догоревшей сижки. |
| Никто не слушает твой клич. | `кинь_клич` без подписчиков (предупреждение). |
| Бесконечный цикл. Мама зовёт. | Предупреждение: цикл без выхода. Проверь `хватит_епт`. |

## 12. Полные примеры

### Пример 1: ФиззБуззь, как завещал Версаль

Классическая задача: числа от 1 до 100; кратные 3 — «Ля'Пивас», кратные 5 — «Ля'Семки», кратные обоим — «Ля'Пивас-Семки».

```
слыш ГопЛя 2.2

по_каждому (i от 1 до 100) {
    чё_если (i % 15 == 0) {
        базарь("Ля'Пивас-Семки")
    } а_чё_если (i % 3 == 0) {
        базарь("Ля'Пивас")
    } а_чё_если (i % 5 == 0) {
        базарь("Ля'Семки")
    } а_нет {
        базарь(i)
    }
}
```

*Вывод:*

```text
1
2
Ля'Пивас
4
Ля'Семки
Ля'Пивас
7
8
Ля'Пивас
Ля'Семки
...
```

### Пример 2: Раздача семок на районе

Комплексный пример: классы, исключения и разбор полётов.

```
слыш ГопЛя 2.2

гоп Кореш {
    у_подъезда семка имя: текст
    за_гаражами семка семки = 0

    кортан Кореш(имя, семки = 0) {
        сам.имя = имя
        сам.семки = семки
    }

    кортан дай(скока) {
        чё_если (скока > сам.семки) {
            кидай новый Косяк(сам.имя + ": у самого нет столько!")
        }
        сам.семки -= скока
        отдай скока
    }

    кортан возьми(скока) { сам.семки += скока }
    кортан сколько() типа сам.семки
}

кортан главный() {
    семка жан = новый Кореш("Жан-Клод", 50)
    семка серёга = новый Кореш("Серёга")

    попробуй {
        серёга.возьми(жан.дай(30))
        серёга.возьми(жан.дай(30))      // тут будет косяк
    } предъявил (Косяк к) {
        базарь("Предъявили: " + к.сообщение)
    } по_понятиям {
        базарь("У Жана осталось: {жан.сколько()}")
        базарь("У Серёги: {серёга.сколько()}")
    }
}

главный()
```

*Вывод:*

```text
Предъявили: Жан-Клод: у самого нет столько!
У Жана осталось: 20
У Серёги: 30
```

Обрати внимание на порядок: блок `предъявил` отработал первым, а `по_понятиям` — в самом конце. И да, первые 30 семок Серёга получил честно. Второй раз не прокатило.

### Пример 3: Асинхронный поход за закуской

слыш ГопЛя 2.2

## 13. Фирменные фишки: чего нет ни в Python, ни в JS

Всё, что было выше, ты где-нибудь уже видел в других языках, только без «епт». Эта глава о вещах, которые придуманы специально для ГопЛи 2.1 и 2.2 (кодовые имена «Ля'Заначка» и «Ля'Мадмуазель») и больше нигде не встречаются. Ну, или встречаются, но у них нет такого настроения.

### по_братски: делим поровну

Оператор `по_братски` берёт значение и раскладывает его по переменным поровну или по долям. Остаток отдаётся первому в списке (старшему), так принято. Значения **добавляются** к тому, что уже лежит в переменных: чужое мы не затираем.

```
слыш ГопЛя 2.2

семка общак = 100
семка жан = 0
семка пьер = 0
семка серёга = 0

по_братски (общак => жан, пьер, серёга)

базарь("{жан} / {пьер} / {серёга}")
базарь("В общаке осталось: {общак}")
```

*Вывод:*

```text
34 / 33 / 33
В общаке осталось: 0
```

Можно делить и по долям: после двоеточия указывается вес.

```
семка старший = 0
семка младший = 0

по_братски (100 => старший: 2, младший: 1)     // доли 2 к 1
базарь("{старший} и {младший}")
```

*Вывод:*

```text
67 и 33
```

> 💡 **Совет от бати**
>
> Если источник записан переменной (`общак`), после дележа в нём останется ноль. Если это просто число, как `100`, тратить нечего: делится чистая сумма. С типом `дробь` остатка нет, делим по-честному, до последней копейки.

### шухер и отбой: прятки от Дворника

Дворник убирает всё, на что никто больше не ссылается. Но иногда у тебя есть заначка, про которую ты помнишь только сам. Кричишь `шухер(объект)`, и Дворник обходит её стороной. Когда опасность миновала, кричишь `отбой(объект)`, и заначка снова доступна для уборки.

```
позвать { шухер, отбой } из "Версаль"

кортан главный() {
    семка заначка = новый Шато("Ля'Заначка")
    шухер(заначка)             // Дворник теперь обходит её стороной

    // ...долгая работа, в которой заначку нигде не видно...

    отбой(заначка)             // можно подметать
}
```

Если вызвать `шухер()` без аргументов, Дворник замирает целиком, пока не прозвучит `отбой()`. Полезно для кусков кода, где любая пауза на уборку недопустима.

```
шухер()                        // Дворник замер, не шелохнётся
посчитай_квартальный_отчёт()   // быстро и без помех
отбой()                        // Дворник вернулся к работе
```

> ⚠️ **Внимание, косяк!**
>
> Заначка без `отбой` называется утечкой памяти. В народе — «забыл, где спрятал». Компилятор заметит и скажет: *«Заначка без отбоя: Дворник в обиде»*. Не доводи до обиды, у Дворника профсоюз.

### на_потом: сделай, когда уйдёшь

Слово `на_потом` откладывает действие до выхода из кортана, как бы он ни завершился: через `отдай`, через `кидай` или просто дойдя до конца. Несколько `на_потом` выполняются в обратном порядке: как пустые бутылки в ящике, последняя лежит сверху и достаётся первой.

```
кортан торговля() {
    семка семок_нет = правда

    базарь("Открыл ларёк")
    на_потом базарь("Закрыл ларёк, домой")
    на_потом базарь("Пустые бутылки сдал")

    базарь("Торгую...")
    чё_если (семок_нет) {
        отдай "закрылись раньше"       // на_потом всё равно отработает
    }
    отдай "день прошёл"
}

семка итог = торговля()
базарь(итог)
```

*Вывод:*

```text
Открыл ларёк
Торгую...
Пустые бутылки сдал
Закрыл ларёк, домой
закрылись раньше
```

> 🏰 **Факт из Версаля**
>
> Идея `на_потом` родилась, когда автор уходил со двора и вспомнил, что не закрыл пивас. С тех пор компилятор помнит за него. Автор очень благодарен.

### кинь_клич и слушай: оповестить весь район

Событийная модель в ГопЛе живёт по дворовым законам. Кто-то **слушает** клич, кто-то его **кидает**, и все подписанные корешы откликаются в порядке подписки. Отписаться можно через `отстань`.

```
слыш ГопЛя 2.2

кортан пришёл_кореш(кто) {
    базарь("Бонжур, " + кто + "! Проходи")
}

слушай "пришёл_кореш" => пришёл_кореш
слушай "пришёл_кореш" => кортан(кто) типа базарь("Шепнул бате про " + кто)

кинь_клич "пришёл_кореш"("Серёга")

отстань "пришёл_кореш"                // все отписались
кинь_клич "пришёл_кореш"("Жан")       // тишина
```

*Вывод:*

```text
Бонжур, Серёга! Проходи
Шепнул бате про Серёга
(предупреждение: никто не слушает твой клич «пришёл_кореш»)
```

> 💡 **Совет от бати**
>
> Если клич кинули, а слушателей нет, компилятор не падает, а лишь вздыхает предупреждением: *«Никто не слушает твой клич»*. Ведь бывает, что орёшь в пустой двор.

### Буфера: по_кругу, Вот_это_буфера и чёткий_бампер(зад)

Буфер в ГопЛе называется **Буфера**. Он умеет держать данные, пока их не заберут. Обычный `Буфера(5)` на пять мест и ни на шаг больше. Если положить лишнее, получишь косяк «Буфера полная». А вот три подруги делают жизнь интереснее:

| Слово | Что делает |
|---|---|
| `по_кругу` | Делает буфер кольцевым: когда мест нет, самое старое вытесняется новым. |
| `Вот_это_буфера(n)` | Выделяет место «с запасом»: запросил n, получил ёмкость 2n. Для тех, кто любит с размахом. |
| `чёткий_бампер(зад)` | Ставит ограничитель на хвост буфера. «Зад» здесь позиция последнего разрешённого места. Дальше не пускает, бросает косяк «БамперКосяк». |

```
// кольцевая: старое вытесняется
семка б = новый Буфера(3) по_кругу
б.положи("раз")
б.положи("два")
б.положи("три")
б.положи("четыре")                    // «раз» вытеснено
базарь(б.всё())                       // [два, три, четыре]

// с запасом и с бампером
семка в = новый Вот_это_буфера(4)
базарь(в.ёмкость)                     // 8
в.чёткий_бампер(зад = 6)              // дальше 6-й позиции не пускаем

попробуй {
    по_каждому (i от 1 до 9) { в.положи(i) }
} предъявил (БамперКосяк к) {
    базарь(к.сообщение)
}
```

*Вывод:*

```text
8
Бабах! Чёткий бампер не пропустил: зад на позиции 6
```

> 🏰 **Факт из Версаля**
>
> Бампер придумали не ради красоты. Без него запись за пределы буфера молча портила соседние данные. С бампером программа врезается красиво, с сообщением и без последствий для соседей.

### Сижка(сигара, папироска): ленивые потоки

**Сижка** — ленивый поток значений. Значения не готовятся заранее, а считаются по одной «затяжке» (`.затянись()`). У сижки два вида:

| Вид | Что это | Когда брать |
|---|---|---|
| `сигара` | Длинная, потенциально бесконечная. Значения вычисляются кортаном по номеру затяжки. | Бесконечные ряды, генераторы, ленивые вычисления. |
| `папироска` | Короткая, конечная. Берёт значения из готовой кучки и сгорает до бычка. | Обычный перебор известного набора. |

```
слыш ГопЛя 2.2

// папироска: сгорает за три затяжки
семка п = Сижка(папироска, ["раз", "два", "три"])
грызи_пока (не_а п.бычок) {
    базарь(п.затянись())
}

// сигара: тянется бесконечно, но лениво
семка с = Сижка(сигара, кортан(i) типа i * i)
базарь(с.затянись())                  // 0
базарь(с.затянись())                  // 1
базарь(с.затянись())                  // 4
базарь(с.возьми(3))                   // [9, 16, 25]
```

*Вывод:*

```text
раз
два
три
0
1
4
[9, 16, 25]
```

Сижку можно пустить в `по_каждому`, но с сигарой помни про `хватит_епт`, иначе цикл будет бесконечным и мама позовёт. Затяжка по догоревшей сижке даёт косяк *«Бычок. Тянуть нечего»*.

> ⚠️ **Внимание, косяк!**
>
> Минздрав предупреждает: бесконечные сигары вредят вашему процессору. Живым людям курение вредит ещё сильнее, так что в реальной жизни лучше ограничиться сижками из кода.

### Мадмуазель: строгий режим с хорошими манерами

Обычный ГопЛя прощает многое: «5» вместо 5 съест, `пусто` проглотит. Но если перед кортаном или гопом написать `мадмуазель`, включается строгий режим. Никаких неявных приведений типов, никакого `пусто` без предупреждения. Мадмуазель любит порядок и обращается на «вы». Режим можно включить на весь файл: `слыш ГопЛя 2.2 мадмуазель`.

```
мадмуазель кортан налей(кому: текст, сколько: дробь): текст {
    отдай "{кому}: {сколько} л"
}

налей("Жан", 0.5)               // ок, как положено
налей("Жан", "полведра")        // КОСЯК при компиляции
налей(пусто, 0.5)               // КОСЯК: пусто без предупреждения

// чтобы разрешить пусто, скажи об этом вежливо
мадмуазель кортан поздоровайся(кому: текст?) {
    отдай "Бонжур, " + (кому ?? "незнакомец")
}
```

Если нарушить правила, компилятор ответит: *«Мадмуазель в шоке: «текст» вместо «дроби». Так не делают»*. Знак `?` после типа означает «допускаю пусто, но предупредите заранее».

> 💡 **Совет от бати**
>
> Строгий режим удобно включать на проектах, где ошибки типов стоят дорого. Для быстрых скриптов оставляй обычный режим: Мадмуазель не любит спешки.

### Сводка фишек

| Фишка | Что делает | Чем отличается от других языков |
|---|---|---|
| `по_братски` | Делит значение поровну или по долям | Готового оператора нет: обычно пишут цикл и считают остаток руками |
| `шухер / отбой` | Прячет объект или весь Дворник от уборки | Есть похожие механизмы, но не с такой интонацией |
| `на_потом` | Откладывает действие до выхода из кортана | Похоже на defer и finally, но проще и читается вслух |
| `кинь_клич / слушай` | События с подпиской и отпиской | Похоже на EventEmitter, но с настроением |
| `Буфера / по_кругу` | Буфер, в том числе кольцевой | Кольцо включается словом, а не отдельным классом |

## 15. Часто задаваемые вопросы

**В: Можно ли писать на ГопЛе серьёзные проекты?**

Можно. Серьёзность определяется не языком, а выражением лица разработчика на созвоне.

**В: Почему «пивас» нельзя изменить?**

Потому что константа. Налитое пиво обратно не переливают. Для переменного содержимого используй «семку».

**В: Что быстрее: «грызи_пока» или «по_каждому»?**

По_каждому чуть быстрее: он знает, сколько семок в пачке. Грызи_пока грызёт, пока не надоест.

**В: Где в ГопЛе точка с запятой?**

Нигде. Точка с запятой — это буржуйство, а мы тут из дворянских, но с понятиями.

**В: Как оставить комментарий?**

Через `//` в одну строку или `/* ... */` на несколько. Рекомендуется добавлять комментарии вида «тут батя ругался».

**В: Что делать, если Дворник не приходит?**

Проверить, не вызвал ли ты `подмети()` в цикле. Если вызвал — просить прощения лично.

**В: Сижка вредна для здоровья?**

Для здоровья вредно настоящее курение. Сижка в ГопЛе вредит только процессору, если забыть `хватит_епт`.

**В: Мадмуазель — это просто строгая типизация?**

По сути да. Но с Мадмуазель надо на «вы», по типам и без «пусто» в кармане.

**В: Как отладить программу?**

Расставь `базарь()` везде, где подозреваешь косяк. Если подозреваешь все строки — это не отладка, это экскурсия.
